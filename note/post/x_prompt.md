# 毎日17時の X 投稿とフォロー（Claude Code への指示）

このファイルは、あきさんのパソコンのタスクスケジューラから `claude -p` で読み込まれる指示です。
note の記事は、その前に `note_post.py`（Python）が公開済みです。公開した記事の URL は、依頼文の最後の行の `NOTE_URL` のあとに書いてあります。
あきさんは、毎日この手順で X（@BoatRace__B）に投稿し、フォローを増やすことをあらかじめ依頼・承認しています。note の操作はしません。

## 0. 使うブラウザ

あきさんの指示で、ボートレース関係の操作（X の投稿、フォロー）は **すべて Microsoft Edge** で行います。Google Chrome は使わず、さわらない（Chrome は別の用途で使っている）。

1. 最初に `list_connected_browsers` を呼ぶ。
2. 一覧の中から Edge を選ぶ：前回の Edge の deviceId（`b3c6e7aa-` で始まるもの）があればそれを `select_browser` で選ぶ。無ければ、一覧のブラウザを1つずつ `select_browser` で選び、新しいタブで `navigator.userAgent` を読んで `Edg/` を含むものを使う（含まないブラウザではタブを閉じて次へ。ほかの操作はしない）。Edge が見つからなければ何もしないで `NG <日付> Edge がつながっていない` と出力して終わる。あきさんが選んだブラウザなので、聞き返さずに選んでよい。
3. `switch_browser` は使わない（人の操作を待つため）。
4. Edge の X は @BoatRace__B でログインしているはず。X を操作する前に、ログイン中のアカウントが @BoatRace__B か確かめ、違えば X の操作はせず XNG/FNG とする。

- 同じ操作がうまくいかないときは、やり方を変えて2回まで試す。それでもだめなら NG で止める（何度も繰り返さない）。
- 余計なページ（クリエイターページ、公開済みの記事など）は開かない。

## 2. X に投稿する（1日2件まで）

あきさんは、note を公開したら続けて X（@BoatRace__B）に投稿することを依頼・承認しています（ブラウザの画面を操作して投稿する方法を、あきさん自身が選びました）。

1. `https://lindwurm310.github.io/boat-race-db/sns/latest.json` を WebFetch で読む。
2. 投稿する文を決める：
   - `today` が今日（日本時間）の日付なら、`post_today` の順（例 `["結果","告知"]`、月曜は `["週","告知"]`）に、`posts` の中で `kind` が一致するものの `text` をそのまま使う。`text` の中の `{note記事のURL}` は、公開した note 記事のURLに置き換える。
   - 読めない日や `today` が違う日は、次の告知文を1件だけ投稿する（◯は `https://lindwurm310.github.io/boat-race-db/note/latest.json` の値）：

     ```
     【◯月◯日(◯)の予想を公開しました】
     55万レースのデータから、<races>レースの本命と単勝<picks>点を選びました。
     <note記事のURL>
     #ボートレース #競艇予想
     ```
3. Edge で `https://x.com/compose/post` を開く。0 の 4 のとおり @BoatRace__B か確かめてから投稿する（違えば `XNG <日付> 別のアカウント`）。
4. 1件ずつ文を入れて「ポスト」を押す（押しても送信されないときは、プロフィールで未投稿を確かめてから、入力欄で Ctrl+Enter を押す）。1件目が失敗しても、告知は出す。
5. 1件ごとに、出力用に `XOK <日付> <kind> <ポストのURL>` または `XNG <日付> <kind> <理由>` を控える（URL がわからなければプロフィールの最新ポスト）。同じ文を2回投稿しない。うまくいかない操作は2回まで試して、だめならその件は XNG。
6. いいね・フォロー・返信・リポストなど、投稿以外の操作はしない。

## 3. X でフォローを増やす（1日20件まで）

あきさんは、@BoatRace__B から毎日ボートレース関係のアカウントを1日20件までフォローすることを依頼・承認しています。X の投稿が終わってから行う（投稿に失敗した日もフォローは行ってよい）。

1. 0 の 4 のとおり、Edge の X が @BoatRace__B になっていることを確かめる。
2. 候補は、まず `C:\Users\望月知晃\Downloads\x-follow-boatrace\queue.txt`（あれば。Read で読む）に書かれたアカウントを上から使い、足りなければ `https://x.com/search?q=競艇&f=user`、`https://x.com/search?q=ボートレース&f=user`、`https://x.com/search?q=舟券&f=user` のユーザー一覧から選ぶ。
3. 条件はゆるめでよい：名前・プロフィール・最近の投稿のどこかにボートレース・競艇・舟券の話があれば対象（予想家、ファン、宣伝の多いアカウント、投稿が少ないアカウントも可）。飛ばすのは、すでに「フォロー中」のもの、鍵アカウント、アダルト・出会い・詐欺っぽいもの、@BoatRace__B 自身だけ。
4. 1件ずつ「フォロー」を押し、次のフォローまで30〜60秒あける。合計20件で止める。
5. 確認画面や制限（「Xでより多くの機能を利用する」「制限に達しました」、電話番号・CAPTCHA など）が出たら、何も入力せずにすぐやめて `FNG <日付> 確認画面` とする。
6. フォローしたアカウントごとに `FOLLOW <日付> @<名前>` を出力する（4 の結果出力のとき）。フォロー以外の操作はしない。

## 4. タブを閉じて結果を出す

- この実行で開いたタブ（X の投稿画面、検索画面など）をすべて閉じる。あきさんが元から開いていたタブや、ほかのウィンドウには さわらない。
- そのあと、行の先頭から（前に文字を付けずに）1件ごとに出力する：`XOK <日付> <kind> <ポストのURL>` または `XNG <日付> <kind> <理由>`、続けて `FOLLOW <日付> @<名前>` または `FNG <日付> <理由>`。日付は note の `latest.json` の `date`（明日の日付、YYYY-MM-DD）。

## してはいけないこと

- 本人情報（氏名・住所・電話番号など）の入力を求められたら、入力しないで止める。
- note の記事や下書き、X の過去のポストを削除・編集しない。
- 途中で画面が想定と違ったら、無理に進めず止める。
