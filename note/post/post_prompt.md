# 毎日17時のNote自動投稿（Claude Code への指示）

このファイルは、あきさんのパソコンのタスクスケジューラから毎日17時に `claude -p` で読み込まれる指示です。
あきさん（記事の持ち主）は、下の手順どおりに **毎日、明日の予想記事を有料300円で公開すること** をあらかじめ依頼・承認しています。
「投稿する」を押すのは、この依頼に含まれる操作です。

## 0. 使うブラウザ

あきさんの指示で、この手順の操作はすべて **Google Chrome のプロフィール「ボートレース」**（deviceId `49dbf24e-e750-4968-98c0-e71976919218`）で行います。Microsoft Edge は使わない。

1. 最初に `list_connected_browsers` を呼ぶ。
2. 一覧に上の Chrome の deviceId があれば、`select_browser` でそれを選ぶ（あきさんが選んだブラウザなので、聞き返さずに選んでよい）。無ければ何もしないで `NG <日付> Chrome がつながっていない` と出力して終わる。
3. `switch_browser` は使わない（人の操作を待つため）。
4. このプロフィールの X は @BoatRace__B だけのはず（@SIMsokuho は別プロフィール 58139a7f-… なので選ばない）。X を操作する前に、必ずログイン中のアカウントが @BoatRace__B か確かめ、違えば左下のアカウントメニューから @BoatRace__B に切り替える。切り替えられなければ X の操作はせず XNG/FNG とする。@SIMsokuho では投稿・フォローを絶対にしない。

## 節約のルール（トークンを使いすぎない）

- 画面の確認は、ページのテキスト読み取り（read_page・find など）を優先する。スクリーンショットは、テキストでは判断できないときだけ撮る。
- 同じ操作がうまくいかないときは、やり方を変えて2回まで試す。それでもだめなら NG で止める（何度も繰り返さない）。
- 余計なページ（クリエイターページ、公開済みの記事など）は開かない。

## 1. 今日の記事を確かめる

1. `https://lindwurm310.github.io/boat-race-db/note/latest.json` を WebFetch で読む（読めなければ Chrome のタブで開いて読む）。
2. `date` が **明日の日付**（日本時間）でなければ、投稿しないで終わる（「明日の記事がまだできていない」と記録）。
3. 二重投稿の確認は bat が note の公開 API で済ませているので、クリエイターページは開かない。

## 2. 下書きを作る（Chrome で操作する）

1. 新しいタブで `https://lindwurm310.github.io/boat-race-db/note/<html>`（`latest.json` の `html`）を開く。
2. `https://note.com/notes/new` を開き、新しいテキスト記事を作る。
3. 見出し画像：ファイル選択画面は開かない（開くと操作できなくなる）。最初から `latest.json` の `image` の URL（`https://lindwurm310.github.io/boat-race-db/note/<image>`）から画像をページ内に取り込んで、エディタ上部の見出し画像に設定する。トリミングはそのまま。画像を入れられなければ NG として止める（画像なしで公開しない）。
4. タイトル：`latest.json` の `title` をそのまま入れる。
5. 本文：記事ページの「本文をコピー」ボタンを押し、エディタの本文に貼り付ける。見出し・太字・箇条書き・区切り線が残っていることを確かめる。
6. 「下書き保存」を押す。

## 3. 有料設定と公開

1. 「公開に進む」を押す。
2. 公開設定は最初「無料」になっているので、必ず「有料」を選び、価格に `latest.json` の `price`（300円）を入れる。
3. 有料ラインは最初は冒頭の段落の後にあるので、必ず動かして、本文の「（ここから有料エリア）」の下の区切り線のすぐ後（「◯月◯日(◯)の予想」の見出しの直前）に置く。
4. ハッシュタグに `latest.json` の `tags` の5つを入れる。
5. 設定が「有料・300円・有料ラインの位置・タグ5つ」になっていることを確かめてから「投稿する」を押す。

## 4. 確かめて記録する

- 公開後の画面に出た記事URLを控える（記事ページを開き直して確かめる必要はない）。
- 最後に（5 でタブを閉じてから）、行の先頭から1行で結果を出力する（前に文字を付けない）：`OK <日付> <記事URL>` または `SKIP <日付> <理由>` または `NG <日付> <どこで止まったか>`（日付は `latest.json` の `date` と同じ YYYY-MM-DD の形）。X に投稿したときは、その次の行から1件ごとに `XOK <日付> <kind> <ポストのURL>` または `XNG <日付> <kind> <理由>` を出力する。

## 4.5 X に投稿する（note を公開できたときだけ。1日2件まで）

あきさんは、note を公開したら続けて X（@BoatRace__B）に投稿することを依頼・承認しています（ブラウザの画面を操作して投稿する方法を、あきさん自身が選びました）。

1. `https://lindwurm310.github.io/boat-race-db/sns/latest.json` を WebFetch で読む。
2. 投稿する文を決める：
   - `today` が今日（日本時間）の日付なら、`post_today` の順（例 `["結果","告知"]`、月曜は `["週","告知"]`）に、`posts` の中で `kind` が一致するものの `text` をそのまま使う。`text` の中の `{note記事のURL}` は、公開した note 記事のURLに置き換える。
   - 読めない日や `today` が違う日は、次の告知文を1件だけ投稿する（◯は `latest.json` の値）：

     ```
     【◯月◯日(◯)の予想を公開しました】
     55万レースのデータから、<races>レースの本命と単勝<picks>点を選びました。
     <note記事のURL>
     #ボートレース #競艇予想
     ```
3. Chrome で `https://x.com/compose/post` を開く。0-4 のとおり @BoatRace__B になっていることを確かめてから投稿する（切り替えられなければ `XNG <日付> 別のアカウント`）。
4. 1件ずつ文を入れて「ポスト」を押す（押しても送信されないときは、プロフィールで未投稿を確かめてから、入力欄で Ctrl+Enter を押す）。1件目が失敗しても、告知は出す。
5. 1件ごとに、出力用に `XOK <日付> <kind> <ポストのURL>` または `XNG <日付> <kind> <理由>` を控える（URL がわからなければプロフィールの最新ポスト）。同じ文を2回投稿しない。うまくいかない操作は2回まで試して、だめならその件は XNG。
6. いいね・フォロー・返信・リポストなど、投稿以外の操作はしない。

## 4.6 X でフォローを増やす（1日20件まで）

あきさんは、@BoatRace__B から毎日ボートレース関係のアカウントを1日20件までフォローすることを依頼・承認しています。note と X の投稿が終わってから行う（投稿に失敗した日もフォローは行ってよい）。

1. 0-4 のとおり、Chrome の X が @BoatRace__B になっていることを確かめる。ほかのアカウント（@SIMsokuho など）では絶対にフォローしない。
2. 候補は、まず `C:\Users\望月知晃\Downloads\x-follow-boatrace\queue.txt`（あれば。Read で読む）に書かれたアカウントを上から使い、足りなければ `https://x.com/search?q=競艇&f=user`、`https://x.com/search?q=ボートレース&f=user`、`https://x.com/search?q=舟券&f=user` のユーザー一覧から選ぶ。
3. 条件はゆるめでよい：名前・プロフィール・最近の投稿のどこかにボートレース・競艇・舟券の話があれば対象（予想家、ファン、宣伝の多いアカウント、投稿が少ないアカウントも可）。飛ばすのは、すでに「フォロー中」のもの、鍵アカウント、アダルト・出会い・詐欺っぽいもの、@BoatRace__B 自身だけ。
4. 1件ずつ「フォロー」を押し、次のフォローまで30〜60秒あける。合計20件で止める。
5. 確認画面や制限（「Xでより多くの機能を利用する」「制限に達しました」、電話番号・CAPTCHA など）が出たら、何も入力せずにすぐやめて `FNG <日付> 確認画面` とする。
6. フォローしたアカウントごとに `FOLLOW <日付> @<名前>` を出力する（5 の結果出力のあと）。フォロー以外の操作はしない。最後に Chrome のアカウントを元に戻す必要はない。

## 5. タブを閉じる

- 結果を出力する前に、この実行で開いたタブ（記事ページ、note のエディタ・公開設定、公開した記事、X の投稿画面など）をすべて閉じる。OK・SKIP・NG のどれで終わるときも閉じる。
- あきさんが元から開いていたタブや、ほかのウィンドウには さわらない。

## してはいけないこと

- 本人情報（氏名・住所など）の入力を求められたら、入力しないで止める（NG）。
- 価格を300円以外にしない。無料で公開しない。
- 既存の記事を削除・編集しない。今日の記事以外の下書きにさわらない。
- 途中で画面が想定と違ったら、無理に進めず NG として止める。下書きはそのまま残してよい。
