# 宣伝のしくみと毎日やること

宣伝の軸は「X で毎日、無料の予想1点と前日の結果を正直に出し、note へ誘導する」こと。
GitHub（github.com・github.io）の URL や「GitHub で作っている」ことは、X・note・Zenn など外に出すものには書かない。
検証（過去10年を予想し直したもの）と実戦（レース前に公開した予想）は、どこでも分けて書く。

## 自動で作られるもの（自分で見る用。外には出さない）

| ページ | 中身 | 更新 |
|---|---|---|
| [実戦成績](https://lindwurm310.github.io/boat-race-db/jisseki/) | 公開した予想の全件の答え合わせ・通算・収支の推移・注意書き | 毎朝6時・毎晩22時半 |
| [X の投稿文](https://lindwurm310.github.io/boat-race-db/sns/) | 夕方の記事告知・朝の無料予想・夜の結果・週のまとめ。「Xで投稿」ボタン付き | 16時・6時・22時半 |
| `jisseki/og.png` | 実戦成績の画像。投稿文のページから保存して、夜・週の投稿に添付する | 同上 |

作っているのは `analysis/promo.py`（ワークフロー yosou-page・yosou-check-today・note-daily から呼ぶ）。

## 毎日やること（1日3回、各1分）

1. **8時台**: 投稿文のページを開き、「朝」の「Xで投稿」→ ポスト
2. **17時ごろ**（note の記事が出たあと）: 「夕方」を投稿
3. **22時半以降**: 成績画像を保存して添付し、「夜」を投稿。月曜の夜は「週」も

X は画面の自動操作による投稿を規約で禁止しているため、投稿だけは手で押す（「Xで投稿」で文入りの投稿画面が開く）。
完全に自動にしたいときは X の API（有料プラン）が必要。

## 一度だけやること

- [ ] X のアカウントを作る（名前の例: 「55万レースの統計予想」）。アイコンは `note/design/out/icon_*` から
- [ ] プロフィール文（下）を入れ、ウェブサイト欄に note の URL を入れる
- [ ] note の無料記事「55万レースのデータベースからみる統計学の予想」を X の固定ポストにする（文は下）
- [ ] note の「特定商取引法に基づく表記」の設定を確かめる
- [ ] Zenn に技術記事を出す（下書き: `promo/zenn_article.md`。Zenn の CLI かブラウザのエディタに貼る）

### プロフィール文（X・note 共通、160字以内）

```text
1997年からの全レースを入れた自作DBと統計モデルでボートレースを予想。過去10年の検証で単勝回収率107.5%。実戦の成績は外れも含めて全部公開。毎朝無料予想、毎晩結果報告。舟券は20歳から
```

### 固定ポスト

```text
55万レースのデータで「長く続けても負けない買い方」を探しました。

条件だけの必勝法はほぼ偶然。残ったのは「勝つ確率×オッズ」が1を超える艇の単勝だけで、過去10年の検証で回収率107.5%。

しくみと実戦の成績（外れ込み）は無料で読めます
https://note.com/lindwurm310
```

## 書かないこと

- 「必ず」「絶対」「稼げる」「的中保証」「返金保証」「月〇万円」
- 検証の数字だけを「実績」として出すこと（必ず「過去10年の検証」と書く）
- 当たった日だけの報告（負けた日も同じ形で出す）
- 舟券の購入代行・お金を預かること
- BOAT RACE の公式ロゴ・公式画像・選手の写真
- 有料広告、自動フォロー、大量のリプライ・DM
- GitHub の URL（github.com・github.io）
