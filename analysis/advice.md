# 買い方の基本
- 中心は単勝の買い目 (期待値1以上)。過去10年の検証では毎年回収率100%を超えている (2016〜2026年で 102〜114%)。
- 3連単・3連複はどの買い方も回収率75〜85%で、続けると減る。楽しむなら少額で、本命1着確率70%以上の堅いレースに絞る。
- ◎○▲ BOX・◎○▲△ BOX・3連複の5艇 BOX は、でたらめに買うより悪い。買わない。

# 買う前に確かめること
- 予想は前日までのデータで作っている。締切前に「直前情報」で展示タイム・スタート展示・風・波を確かめる。
- 実際のオッズが予想オッズより低いと期待値1を割る。単勝の買い目でもオッズが下がっていたら見送る。
- 本命1着確率35%未満のレースは荒れやすく、予想が当たりにくい。

# お金のこと
- 1日の予算を先に決める。負けを取り返そうと点数を増やさない。
- 的中が10回未満の期間の回収率は、1回の大きな配当で大きく変わるので当てにしない。
