# 追加の情報を足すと予想はどう変わるか（2026-11-14）

展示タイムの検証（`analysis/tenji/README.md`）と同じ方法で比べた。

## 比べ方
- 期間: 2021-10-26〜2026-10-24 の5年（277,838レース）。1年ずつ、その年より前の2年だけで学習し直して予想した。テストの年は学習に使っていない
- モデル: 今の予想モデル（v4・v3学習）を「なし」とし、それに1グループずつ足したモデルと比べた。学習データ・学習方法・買い方・レースは全部同じ
- 単勝の期待値に使うオッズ予想にも、同じ特徴量を入れた（展示の検証の「展示o」と同じ）
- 1点100円。払戻は公式の確定配当（締切時点のオッズ）

## 相関（5年、`morning/corr_morning.csv`）
- rho_finish: 着順とのスピアマン相関。負なら、値が大きいほど上の着になる
- r_resid: 今の予想の1着確率を引いた残りとの相関。今の予想が知らないことをどれだけ持っているかを表す。今の予想に入っている当地勝率・今節の着順・モーター2連率は ±0.004 以内で、展示タイムは −0.059

当地・今節の着は着順との相関が強い。ただ、今の予想にある当地勝率・今節の着順と同じ情報なので、残りとの相関はほぼ 0 になる。今の予想が知らない情報を持っているのは、モーターと今節の展示タイム（展示が良いモーター・その節に展示が良い選手）と、モーターの直近の成績だった。

## まとめ（朝から使える項目）
- **モーターの今期成績**と**今節の成績**は、朝の予想に足すと的中率も回収率も上がる。モーターは3連単・3連複で +1〜2.5pt、単勝の期待値買いで +2.9pt。展示タイムを足したとき（+1〜2pt）と同じくらいか、それより大きい。しかも朝から使える
- 効いているのは、モーターの「展示タイムの良さ」と「直近の成績」、今節の「展示タイムの良さ」。今の予想にある2連率（今期の累計で、乗った選手の腕が混じる）より、モーターの調子を表している
- ボート・当地・体重は変わらない。当地・今節の着順は、今の予想にもう入っている
- 100%を超える買い方は増えない。3連単・3連複は 76〜83% のまま
