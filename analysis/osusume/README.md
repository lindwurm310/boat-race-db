# 毎日1,000円で単勝を買うときの、一番良い買い方

`budget_bt.py` で、過去5年（2021年10月〜2026年10月、1,825日）を検証した。予想は、その年より前のデータだけで学習したモデル（今の予想 v5 とほぼ同じ「朝全部」）のもの。結果は `budget_1000.csv`。

- 候補: 期待値（1着確率 × 予想オッズ）1.1以上、1着確率10%以上の艇の単勝。朝 9:30 の自動投票に合わせて、締切 9:40 より前のレースは除く。
- その日の候補を期待値の高い順に N 点選び、1,000円 ÷ N（100円単位）ずつ買う。

| 買い方 | 1日 | 回収率 | 年ごと | プラスの月 | 一番悪い月 | 最大のへこみ |
|---|---|---|---|---|---|---|
| 上位1点 × 1,000円 | 1,000円 | 122.7% | 103〜135% | 66% | 46% | 41,400円 |
| 上位2点 × 500円 | 1,000円 | 124.7% | 106〜158% | 81% | 54% | 21,000円 |
| **上位3点 × 300円（おすすめ）** | 900円 | **122.8%** | **115〜145%** | **83%** | **80%** | **11,730円** |
| 上位5点 × 200円 | 1,000円 | 119.0% | 112〜123% | 86% | 83% | 11,060円 |
| 上位10点 × 100円 | 1,000円 | 113.1% | 110〜116% | 86% | 90% | 7,370円 |
| 候補を全部 × 100円 | 約2,000円 | 111.6% | 108〜119% | | | |

- 期待値の高い順に絞るほど回収率は上がるが、点数が少ないほど月ごとのぶれが大きい。2点は回収率が一番高いが、悪い月は半分まで下がり、へこみも3点の2倍。3点が、回収率と安定のバランスが一番良い。
- 期待値の下限（1.0〜1.3）はほとんど差がない（上位から選ぶので、選ばれる艇はほぼ同じ）。1着確率の下限は10%が一番良く、15%・20%に上げると回収率が下がる。
- 3連単・3連複の買い方は、同じ5年でどれも回収率 81〜83% だった。
- 実際に公開した予想（2026年11月の、払戻が記録されている9日）で同じように買うと、上位3点で 104%（8,100円 → 8,430円）。日数が少ないので参考まで。
- 注意: 予想オッズは前日までのデータからの見積もりで、締切のオッズとは違う。過去の結果で、これからの回収率を約束するものではない。

## ほかの買い方との比較（2026-11-18）

同じ5年（前半3年で探し、後半2年で確かめた）で、「上位3点×300円」を基準に比べた。差が2%以内なら偶然の幅とみる。

| 買い方 | 回収率 | 前半 → 後半 | プラスの月 | 一番悪い月 |
|---|---|---|---|---|
| 基準: 上位3点 × 300円 | 122.8% | 123% → 122% | 82% | 80% |
| 1位400円・2,3位300円（1日1,000円） | 122.8% | 123% → 123% | 85% | 76% |
| 期待値に比例して配分 | 122.5% | 123% → 122% | 83% | 78% |
| ケリー基準で配分 | 120.9% | 123% → 117% | 80% | 64% |
| 1レース1点まで | 122.9% | 124% → 122% | 82% | 82% |
| 締切11時以降のレースだけ | 124.3% | 126% → 122% | 88% | 82% |
| 予想オッズ3倍超だけ | 121.7% | 122% → 121% | 83% | 74% |
| 1号艇を除く | 122.7% | 123% → 122% | 85% | 77% |
| 1着確率15%以上 | 120.0% | 121% → 118% | 80% | 78% |
| 成績の良い4場だけ | 123.3% | 122% → 125% | 76% | 69% |

- 金額の配分や絞り込みを変えても、回収率はほぼ変わらない（±2%）。場ごとの成績は前半と後半で入れ替わる（例: 津 117% → 89%、若松 104% → 132%）ので、場で絞るのは偶然に合わせるだけになる。
- 「締切11時以降」は前半・後半とも少し良いが、差は1〜2%で、偶然の幅を超えるとは言えない。
- 複勝・2連単・2連複・拡連複は、以前の検証（analysis/README.md）で一番良い買い方でも複勝 約98%、2連・拡連複は 80〜85% で、100%を超えない。これらの券種には予想オッズのモデルがないため、期待値で選ぶ方法はまだ試せていない。

## 採用した買い方（2026-11-18〜）

**締切11時以降のレースで、期待値1.1以上・1着確率10%以上の単勝を、その日の期待値の高い順に3点、1点300円。**
過去5年で回収率 124.3%（的中率 約26%、年ごとに 120〜149%、プラスの月 88%、一番悪い月 82%）。絞る前の候補（1日平均 約19点）を全部買うと 112%。
サイトの「おすすめ舟券」の初期値と、自動投票パネルの「回収率重視（おすすめ）」はこの買い方。
